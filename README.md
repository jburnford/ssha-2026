# Mapping the Colonial Administrative State

Slides for a talk at the Social Science History Association, 2026: *Mapping the Colonial Administrative State: Linked Knowledge Graphs from Colonial and Indian Office Lists, 1867–1947* (Jim Clifford, University of Saskatchewan).

**View the slides:** https://jimclifford.ca/ssha-2026/

Keys: right arrow or space for the next slide, left arrow to go back, `d` for the dark version, `f` for full screen, `r` to replay an animated slide. Add `#12` to the address to open at slide 12.

The talk is a demonstration of work in progress. Counts on the slides are rounded, and the people and institutions on the last slides are names as extracted from the sources, not yet merged or checked.

- `docs/` is the site: one page (`index.html`) with its fonts, images and videos.
- `src/` holds the slide files and the scripts that drew them, for the record. The scripts read project data that is not in this repository, so they will not run from here.

The typeface is Atkinson Hyperlegible Next (Braille Institute, SIL Open Font License).
